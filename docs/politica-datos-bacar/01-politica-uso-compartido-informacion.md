# Política de uso y compartición de la información

**Bacar S.A.**  
**Versión:** 1.0 — borrador interno  
**Fecha:** 28/08/2026  
**Alcance:** toda la empresa  
**Estado:** pendiente de acuerdo Dirección / jefes de área

---

## 1. Para qué existe este documento

Define **cómo se usa y se comparte la información de Bacar S.A.** entre áreas.

Hoy el dato no está en un solo sistema: vive en **Excel**, carpetas, mail, WhatsApp, papel y, en parte, en COSP. Esta política no pretende cambiar eso de un día para el otro. Fija reglas comunes para que el dato circule cuando hace falta y **no se copie sin control**.

Es el **marco general**. El detalle de cada sector (qué planillas tiene, quién las manda, a quién) va en **anexos por área**, que se arman después.

## 2. Qué es “información de la empresa”

Todo lo que Bacar genera o guarda para operar, sin importar el soporte (Excel, PDF, mail, chat, COSP, fotocopia):

- Plantel: nombres, legajos, teléfonos, domicilios, categorías
- Clientes, objetivos, contratos, contactos
- Turnos, coberturas, novedades, horas, liquidación
- Credenciales, fotos, certificados cuando existan
- Costos, facturación, claves y accesos a sistemas

Si un archivo sale de la empresa (cliente, estudio, proveedor), sigue siendo información de Bacar hasta que el destinatario tenga un motivo de negocio para tenerla.

## 3. Reglas de oro

1. **Cada área es dueña de su dato.** RRHH del legajo, Comercial del cliente, Operaciones de lo que pasa en el piso, Administración de haberes y pagos. Nadie “se queda” con el Excel de otro como si fuera propio.
2. **Se comparte lo necesario, no el archivo entero.** Si Operaciones necesita cinco vigiladores para un objetivo, no se manda el plantel completo.
3. **Toda copia tiene dueño, fecha y para qué.** Un Excel sin nombre, sin fecha y reenviado tres veces deja de ser dato: es ruido y riesgo.
4. **Quien recibe no reenvía por inercia.** Si hace falta que lo vea otra persona, se pide o se explica el motivo.
5. **La última versión conocida manda.** Si COSP o el dueño del área ya actualizó el dato, las copias viejas en mail no se siguen usando.

## 4. Dónde vive el dato hoy

| Soporte | Uso típico | Cuidado |
|---------|------------|---------|
| **Excel** | Planteles, horas, listados para el día, cruces entre áreas | Es el canal más usado y el que más se descontrola (copias) |
| **Mail** | Envío puntual a otra área o a un tercero | El adjunto queda en todas las bandejas |
| **WhatsApp / radio** | Operación del momento (cobertura, llegada, reemplazo) | No es archivo. No se mandan padrones ni certificados |
| **Carpetas / papel** | Legajos, contratos, comprobantes | Acceso físico = mismo criterio que un Excel |
| **COSP** | Turnos, legajos, clientes, fichadas, cuando el módulo está en uso | Fuente de verdad de lo que ya está cargado ahí |

Ningún soporte está “prohibido”. Lo que está prohibido es **usar el canal equivocado para el volumen de dato**.

## 5. Cómo se pide y cómo se comparte

1. Se pide **con finalidad**: “necesito los teléfonos de la dotación del objetivo X para esta noche”, no “mandame el Excel de gente”.
2. El área dueña **arma el recorte** (hoja, filtro, lista corta) y lo manda a quien lo necesita.
3. En el archivo o en el mail: **quién lo emitió, fecha, para quién**. Ejemplo de nombre: `dotacion_objetivo-sur_2026-08-28_ops.xlsx`.
4. Si el pedido es recurrente (todas las semanas lo mismo), el anexo de esa área debe decir **quién lo genera y quién lo recibe**, para no improvisar cada vez.
5. Al cliente, al estudio o a un proveedor: **solo lo que el trabajo exige**. El cliente del objetivo no necesita DNI, CUIL, domicilio ni salud del plantel para saber quién cubre.

## 6. Tres niveles (para decidir si se manda o no)

No hace falta un sistema de etiquetas. Con esto alcanza:

| Nivel | Ejemplos | Quién lo ve |
|-------|----------|-------------|
| **Uso interno** | Nombres de la guardia de hoy, objetivo, horario | Áreas que operan ese servicio |
| **Confidencial** | Plantel completo, teléfonos, contratos, horas a liquidar, datos de cliente | Solo las áreas que lo necesitan para esa tarea |
| **Restringido** | Sueldos, CBU, certificados médicos, ART, sanciones, conflictos entre personas | RRHH / Administración / Dirección. No circula por WhatsApp ni se pega en un Excel de operaciones |

Si hay duda, se trata como **confidencial** y se pregunta al dueño del área.

## 7. Excel: reglas concretas

Porque es el medio habitual:

- **Un dueño por planilla maestra.** El resto son copias de trabajo, no “la verdad”.
- **No se trabaja sobre el adjunto del mail de hace un mes** si el dueño ya tiene otra versión.
- **No se guarda el plantel en Drive, OneDrive o PC personal** “para tenerlo a mano”.
- **No se deja el Excel en un grupo de WhatsApp.** Si hace falta una lista, se manda al que cubre y se borra cuando ya no sirve.
- Si el dato **ya está en COSP**, no se mantiene un Excel paralelo como fuente de verdad. El Excel, si existe, es extracto para un uso puntual (una reunión, un cruce, un envío).
- Cuando el trabajo terminó, las copias locales se archivan o se borran. No se acumulan “por las dudas” en el escritorio.

## 8. Áreas (anexos después)

El marco es el mismo para todos. Cada anexo dirá qué información maneja esa área, qué puede compartir y qué no sale.

| Área | Dato que suele “tener” | Anexo |
|------|------------------------|--------|
| Dirección | Visión global, decisiones, costos | Pendiente |
| RRHH | Legajo, novedades, salud, gremio | Pendiente |
| Operaciones | Guardia del día, vacantes, novedades de piso | Pendiente |
| Planificación | Malla, asignaciones, francos | Pendiente |
| Comercial / clientes | Cuentas, objetivos, contratos | Pendiente |
| Administración / liquidación | Horas, haberes, pagos | Pendiente |
| Sistemas | Accesos, COSP, copias de sistemas | Pendiente |

Hasta que exista el anexo, rigen estas reglas generales.

## 9. Qué no se hace

- Mandar el **Excel maestro** de personal o de clientes “por si acaso”.
- Reenviar padrones, fotos de DNI, certificados o CBU por WhatsApp.
- Mezclar en una misma planilla **sueldos** con **teléfonos para el piso**.
- Subir información de Bacar a cuentas personales (mail, Drive, celular de un familiar).
- Dejar planillas en impresoras, pendrives sueltos o PCs desbloqueadas.
- Usar el dato de un área para un fin distinto (p. ej. una lista de RRHH para un contacto comercial no pedido).

## 10. Si algo se descontroló

Se avisa el mismo día al jefe de área y a Sistemas (IT): Excel mandado al destinatario equivocado, celular perdido con planillas, grupo de WhatsApp con un padrón. Primero se contiene (borrar el archivo del grupo, pedir que no se reenvíe); después se ve el alcance. No se espera a “ver si pasa algo”.

## 11. Vigencia

Aplica desde que Dirección la comunique. Se revisa cuando una área sume su anexo o cuando cambie el lugar donde vive el dato (por ejemplo, si un Excel pasa a COSP).

API — El protocolo que permite que dos sistemas de software se comuniquen.
Backend — La parte de una aplicación que el usuario no ve. El servidor, la base de datos, la lógica de negocio.
Base de datos — Donde se guarda toda la información de tu aplicación de forma organizada.
Bug — Un error en el código que hace que la aplicación se comporte de forma incorrecta.
Caching — Guardar temporalmente el resultado de una operación costosa para no repetirla.
CDN — Red de servidores distribuidos que entregan contenido desde la ubicación más cercana al usuario.
Churn — El porcentaje de clientes que cancela su suscripción en un período.
Cloud / Nube — Servidores y servicios disponibles a través de internet, gestionados por terceros.
Cloud Functions — Fragmentos de código que se ejecutan en el servidor cuando ocurre un evento específico.
Deploy — El proceso de poner una versión de la aplicación en el servidor para que los usuarios puedan acceder.
Dominio — La dirección de tu aplicación en internet. tuempresa.com.
ERP — Sistema de gestión empresarial que integra finanzas, RRHH, operaciones y logística.
Firebase — Plataforma de Google que provee base de datos, autenticación, almacenamiento y funciones en la nube.
Firestore — La base de datos NoSQL de Firebase. Organiza datos en documentos y colecciones.
Frontend — La parte de la aplicación que el usuario ve e interactúa.
Git / GitHub — Sistema de control de versiones que registra todos los cambios en el código.
HTTPS — Protocolo seguro que cifra el tráfico entre navegador y servidor.
JWT — Formato estándar para transmitir información de forma segura. Usado para sesiones de usuarios.
KPI — Indicador clave de rendimiento. La métrica que te dice si lográs tu objetivo.
Low-code — Plataformas que permiten construir aplicaciones con poca programación manual.
MRR — Ingresos recurrentes mensuales. La suma de lo que pagan todos tus clientes activos.
MVP — La versión más simple de tu producto que permite validar hipótesis con usuarios reales.
Multi-tenant — Arquitectura donde una instancia del software sirve a múltiples clientes con datos separados.
NoSQL — Base de datos que no usa tablas y filas como las relacionales tradicionales.
Onboarding — Proceso de guiar a un nuevo usuario para que experimente el valor del producto rápidamente.
Product-Market Fit — El momento en que tu producto satisface la demanda de un mercado específico.
Prompt — La instrucción que le das a una herramienta de IA.
React — El framework de JavaScript más popular para construir interfaces web modernas.
Redis — Base de datos en memoria usada comúnmente para caching.
REST API — El estilo de API más común en la web.
SaaS — Software entregado a través de internet como servicio, con modelo de suscripción.
SDK — Conjunto de herramientas que facilita el desarrollo en una plataforma específica.
Serverless — Modelo donde el código se ejecuta en respuesta a eventos, sin gestionar servidores.
SSL/TLS — Protocolos de cifrado implementados como HTTPS.
Stack tecnológico — El conjunto de herramientas, lenguajes y plataformas para construir una aplicación.
UI / UX — Interfaz visual (UI) y experiencia completa del usuario (UX).
Uptime — Porcentaje de tiempo que un sistema está disponible. 99.9% = 8.7 horas de caída al año.
Variables de entorno — Valores de configuración definidos fuera del código para mantener secretos separados.
Webhook — Mecanismo por el que un sistema notifica a otro automáticamente cuando ocurre un evento.
